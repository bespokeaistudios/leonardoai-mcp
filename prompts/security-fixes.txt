- `downloadUrl()` must reject non-HTTPS URLs (only https:// scheme allowed)
- `downloadUrl()` must validate the hostname is cdn.leonardo.ai OR a known Leonardo CDN domain
- Add a ALLOWED_DOWNLOAD_HOSTS set: ['cdn.leonardo.ai']

Note: The code already has HTTPS enforcement and SSRF protection in validateDownloadUrl() — add the hostname allowlist check there.

  try {
    const response = await this.fetchImpl(url, { ...init, signal: controller.signal });
    // ... existing code ...
